Draw a digit

Draw one digit and send it to your own Python code. Nothing leaves this page: no internet, nothing saved.

How to use it

  1. Draw one digit, large, in the middle of the box: with a mouse, a finger or a pen.
  2. Click Copy 784 numbers.
  3. Paste the numbers into the notebook cell 'Draw your own digit' and run it.

Drawing box (280 × 280)

What Python gets: 28 × 28 pixels,
0 = paper, 255 = ink

The numbers are the raw drawing: each one is the average ink of a 10 × 10 block of the box, from 0 (paper) to 255 (ink). Cropping, scaling and centring happen in Python (prepare_drawing), so you can read every step. No mouse or touch screen? Use the typed sketch in the notebook (sketch_to_image).
