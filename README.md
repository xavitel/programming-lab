## How to start a lab

1. Download the lab's zip from **Releases** (right-hand side of this page) and **extract it**.
2. Open the extracted folder in VS Code (File > Open Folder…).
3. Follow `START_HERE.md` inside the folder: select a Python 3.11+ kernel and run the first cell until it prints `READY`.

Nothing needs installing for the CORE of any lab: it uses only the Python standard library.
